# Week 12 – API as a Product

## Kiến thức cần đạt

- **API là sản phẩm**: developer experience, monetization, analytics
- **KPIs**: số lượng developer đăng ký, call volume, error rate

## Kỹ năng cần làm được

- Thiết kế chiến lược ra mắt API (developer portal, docs, sandbox)
- Đề xuất mô hình kiếm tiền từ API (freemium, pay-per-call)

## API đang làm

Nhóm đang xây dựng **Book API** – REST API quản lý danh sách sách với:

- Authentication bằng JWT
- Các endpoint CRUD cho sách
- Webhook notifications (Week 11)
- Swagger UI tại `/docs/`
