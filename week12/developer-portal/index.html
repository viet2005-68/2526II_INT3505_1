Hướng dẫn tích hợp & API Reference

Cổng thông tin endpoint chính thức của Book API v1.0. Tất cả các cuộc gọi production bắt buộc gửi kèm header X-API-Key.

Phương thức Đường dẫn / Endpoint Yêu cầu Auth Mô tả chức năng
GET /api/v1/books X-API-Key Lấy danh sách sách thật lưu trên server
GET /api/v1/books/{id} X-API-Key Xem thông tin chi tiết một cuốn sách
POST /api/v1/books X-API-Key Thêm sách mới vào catalog dữ liệu
DELETE /api/v1/books/{id} X-API-Key Xoá sách khỏi catalog
GET /api/v1/search?q=... X-API-Key (Pro+) Tìm kiếm sách nâng cao (Gated: Lock với gói Free)
